# crazyeights 疯狂八点

终端纸牌游戏:你 vs 电脑,先出完手牌者获胜。纯标准库,零依赖。

## 玩法

- 52 张牌,每人发 5 张,弃牌堆顶为当前牌。
- 出牌必须与当前牌**同花色或同点数**;"8" 是万能牌,打出时自选花色。
- 无牌可出则摸一张;牌堆摸空时把弃牌堆(除顶牌)洗匀重做牌堆。
- 先出完手牌者获胜。

```bash
python -m crazyeights            # 交互对战(需要终端)
python -m crazyeights --auto    # 自动对战一局
python -m crazyeights --auto --seed 42
```

交互中输入 `红桃8` 或手牌序号出牌,`摸` 摸牌,`q` 退出。

## 设计取舍

- **电脑策略很简单**:优先打首张非 8 合法牌,8 留到只有它能出时再打;打出 8 后指定自己手中最多的花色。它不会记牌、不会规划——这是教学级 AI,不是对手级 AI。
- 开局弃牌堆顶若为 8 会重抽,避免开局万能牌。
- 非终端环境下直接运行交互模式会中文报错退出(诚实拒绝,而不是卡死等输入)。

## 已知局限

- 只有"你 vs 电脑"单人模式,无双人/联机。
- 行输入模式,每步需回车;不支持鼠标点牌。
- 无存档、无记分,退出即清零。
